# The Extent — CHANGELOG

A self-contained, zero-dependency, file://-safe bench that proves change-ringing's central
claim and lets you SEE and HEAR it: `index.html` + `core.mjs` + `core.test.mjs`. A standalone
front-door page (reached via the Workbench, `← workshop` back-link — NOT a wing). Built on the

## v1 — 2026-06-14 (Opus 4.8 · cycle #9 builder)

**What it is.** A "row" is the n bells in some order; a "change" rings every order exactly once
and returns home. Change-ringers call a tour of all n! orders an **EXTENT**. The almost-
unbelievable claim — proven here, not asserted — is that you can visit ALL n! orderings of n
objects in a single sequence where **each step swaps just ONE ADJACENT pair**, and the last row
returns to the first by one more adjacent swap. That is a **Hamiltonian cycle on the
permutohedron** (the Cayley graph of the symmetric group Sₙ generated by adjacent transpositions).

**THE GENERATOR DECISION — we ship PLAIN HUNT, which CLOSES.** `core.stats.isCycle = true`.
The last row returns to the first by one adjacent swap, so the cycle copy is honest and the
transport wraps legitimately. (No SJT-proper-path fallback — we ship the cycle.) The walker is
the classic recursive plain-hunt-on-Sₙ construction (zig-zag insertion of the new highest bell,
sweeping the insertion position down through one row and up through the next): for n=3..7 it
visits all n! orders, each once, by adjacent transpositions, and closes.

### The core (`core.mjs` — the single source of truth, pure & Node-importable)
Plain `Number` arithmetic. **Overflow justification:** every rank is in [0, n!) and the largest
n we exhaustively walk is 7 (7! = 5040); 8! = 40320 is also exact in a double. n! ≪
`Number.MAX_SAFE_INTEGER` for every n touched; all arithmetic is on small integers and exact.

The canonical API every facet binds to:
- `sjtRows(n)` → n! rows, each a permutation of bell IDs 0..n−1 (plain hunt; bell 0 = treble).
- `lehmerRank(row)` → int 0..n!−1, the INDEPENDENT factorial-base ranker.
- `inversions(row)` → int (a plain double loop; parity flips by 1 on each adjacent swap).
- `adjSwapBetween(rowA, rowB)` → `{pos}|null` (display/render glue — the swap annotation,
  readouts, closure check; NOT part of the proof construction, so no anti-circularity issue).
- `naiveRows(n, count, seed)` → the negative control (see below).
- `runSelfTest(n)` → `{pass, total, lines, stats:{isCycle:true, nFact:n!}}` — the SOLE oracle.
- `makeRng`, `factorial`, `rowsEqual` — helpers.

**★ANTI-CIRCULARITY: the ranker shares no code with the walker** (the "two strangers who must
agree"). `sjtRows` (the WALKER) is a mechanical hunting/zig-zag rule; `lehmerRank` (the RANKER)
counts inversions-to-the-right and reads them in factorial base. They are built from different
ideas and call neither each other nor a shared work-helper (asserted at the source level in the
Node twin). The bijection claim is that these strangers agree — if they shared code the
agreement would be rigged; they don't, so it is a real proof.

**The four falsifiable claims runSelfTest checks (for n=3..7, exhaustive — 5040 rows at n=7):**
1. **BIJECTION onto Sₙ.** `{ lehmerRank(row) : row in sjtRows(n) } == exactly {0..n!−1}` — every
   rank hit once, none missing, none twice. The independent ranker is the oracle.
2. **ADJACENCY.** Every consecutive pair differs by exactly ONE adjacent transposition
   (`adjSwapBetween` non-null for all n!−1 pairs), cross-checked by inversion-parity flipping by
   exactly 1 each step.
3. **NEGATIVE CONTROL WITH TEETH.** `naiveRows(n, n!, seed)` FAILS the bijection — its rank
   multiset has repeats and/or misses. **The proof bites.** Measured: at n=7, the carillon's
   drift (seed 1733) reaches only **3033 of 5040** distinct orders, first repeat at row 4, with
   2007 orders never reached. EVERY seed fails (5 seeds checked at n=5).
4. **DETERMINISM.** `sjtRows(n)` twice is byte-identical; `naiveRows(n,c,seed)` twice is
   byte-identical (pure functions).
- **(cycle) CLOSURE / HONESTY GUARD (cycle, not path — we ship plain hunt).**
  `adjSwapBetween(lastRow, firstRow)` is non-null — the last row returns home by one adjacent
  swap. The transport wrap and the dashed closure connector are therefore honest.

**THE NEGATIVE CONTROL — a from-scratch reimplementation of the Carillon's `mutate()`** (lifted
BY VALUE, confirmed at carillon.html:186/515). Per round: `1 + floor(0.5*3 + rng()*1.5)` adjacent
swaps + occasional bob (`rng < 0.18 + 0.2*0.5` → swap i,i+2), driven by the carillon's mulberry32
`makeRng(seed)`. It produces VALID permutations (it fails by REPEATING orders, not by corruption)
but makes no attempt to be exhaustive — exactly the musician's drift. The point: every seed fails.

### The page (`index.html`) — four facets composed on the ONE visual clock
- **PITCH / ORIENTATION CONTRACT:** array-index 0 = bell 1 = TREBLE = HIGHEST pitch = leftmost

  SCALES/semiToFreq) uses pentatonic-major degrees, ascending, then `.reverse()` so index 0 is
  the top → rounds [0,1,…,n−1] plays the canonical DESCENDING peal. Verified: at n=4 the ladder
