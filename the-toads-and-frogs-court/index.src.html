The Numbers Room · the second kingdom past Nim

The Toads & Frogs Court

In impartial Nim both players share every move, so one nimber decides who wins. Here the colours move differently: your Toads march right, the flint Frogs march left — each can slide one square ahead or leap a single opponent (who is not captured), and a side with no move loses. Different move-sets make this a partisan game, and a nimber is no longer enough — it needs a surreal Conway value, which the brass loupe below names for every position: a number, the star ∗, an infinitesimal ↑/↓, or a value with no short name at all.

Why a number, and not a Nim-number? ▸
Nim is impartial: from any heap, Left and Right have the exact same moves, so the Sprague–Grundy theorem collapses every position to a single nimber and the whole game becomes XOR-arithmetic. Toads & Frogs is partisan — Left can only push Toads right, Right only push Frogs left — so that collapse fails. Conway's answer is to give every position a recursive value value(G) = { Toad-options | Frog-options }, reduced to canonical form by the simplicity rule. Out of that fall things Nim never needed: the fuzzy star ∗ (a first-player win that is neither positive nor negative), and the infinitesimals ↑ and ↓ — values smaller than every 1/n yet not zero. The loupe reads each off the live algebra; it never makes a name up.

Court
Nim is impartial — both sides share every move, so one nimber settles it. Here the colours move differently, so a single number cannot. Conway's value(G) = { Left's options | Right's options }, reduced to canonical form, is the surreal that can. The loupe never recomputes the winner from a formula: it asks two independent oracles — the value algebra and a colour-blind negamax — and shows you only what both agree on. ∗ means first-player-wins; value 0 means whoever moves now eventually runs out of moves and loses; ↑ is an infinitesimal Toad edge — positive, yet smaller than every 1/n. ↗ The Nimber Strip · the impartial cousin — there both players share every move, so one nimber decides it; here the colours move differently and the value blooms into a surreal.
