The Reaction Balancer

The beam does not weigh grams. It weighs disagreement — every atom one pan holds that the other does not. Nothing arrives balanced: set the coefficients yourself, and the arm leans. The brass studs riding the arm tell you which element is doing the leaning and how far out it sits. Bring the arm to true level and the whole rig goes quiet — and it cannot go quiet while it is lying to you.

Each element is one linear equation. The arm's lean is the size of the residual vector relative to the atoms on the pans, signed by whichever element is furthest out — so a small reaction one atom short leans as plainly as a large one. Because a shortfall of one element can never pay off a surplus of another, the arm reads level if and only if A·c = 0. That is the whole honesty of the instrument: what you see level cannot lie about what is true. Some species genuinely cannot be reconciled — the negative control holds an element with no column on the far side to answer it, and the bench says so in words rather than sulking. The atoms you reassemble here are the same ones the Cavern takes apart.
