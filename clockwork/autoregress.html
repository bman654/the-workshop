The Snake That Eats Its Tail

Generation is a loop that feeds on its own last word. I write one token, then read everything — including that token back in and write the next. Output becomes input, tick by tick. Press STEP and watch the just-emitted tile slide onto the right end of the tape and immediately feed the next pick. Press FORK to re-run from the same prompt with one seed nudged: two tapes share tiles until the first disagreeing draw, then split and never re-converge. The toy vocabulary is illustrative; the loop is exact and reproducible from (prompt, seed) alone.

The loop

A prompt is on the tape. Each STEP: read the whole tape, the last token picks which logits to read, the die rolls, the new tile clips on the right.

Re-read only the prompt each step and pin the die to its top word — never append the emission. The read never moves AND the roll never wanders, so it stutters the same token forever and never builds a sentence. Isolates feed-back, not sampling, as the thing that makes generation.

The self-test proves two things, checked id-by-id over a full run: (1) the generated sequence is exactly reproducible from (prompt, seed) down to the token id; (2) the feedback identity — step-N's input === step-(N−1)'s input with the emitted id appended. The neg-control isolates feed-back: cut it and the run stutters one token forever, never a sentence. The softmax / sampler / RNG are byte-identical to the Temperature Dial and The Next Word.  ·  Back to the wing

Honest about the toy: the emitted tokens are a deterministic deck-hop over a frozen toy vocabulary — not real language; this bench claims no sentence semantics. What is exact, and all it claims, is the reproducibility and the feedback identity above. A real model fans 100,000+ tokens; what is byte-for-byte the same is the loop — emit, append, re-read.
