↗ Daedalus — where this labyrinth was carved

Daedalus builds the labyrinth; here Theseus walks out of it — provably. A perfect maze is a tree, so its one path is trivially shortest. So we braid it (open dead-ends → loops → many routes) and weight the corridors (some slow, some quick) until the route that looks shortest is no longer the one that costs least. Then we don’t trust the picture — we prove the thread minimal with three unrelated witnesses.
