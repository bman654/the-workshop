Two Coils, One Flux

A primary coil (left) drives a changing flux Φ(t) through the shared iron core; a secondary coil (right) reads the SAME flux with its own turn count. Each winding's voltage is −N·dΦ/dt, so V_s/V_p === N_s/N_p exactly — the turns ratio is the only lever. Slide the turns to step the voltage up or down; the power V·I is carried across untouched.

The Alternator

The Knife-Switches

Unlink the core breaks the shared iron so the secondary sees a static field — V_s drops to zero for ANY N_s. DC primary stops the change (ω=0) so dΦ/dt=0 and both meters go dead. A transformer needs CHANGE.

This is the Hall's coil, doubled: there ONE coil read the moving magnet's flux; here a SECOND coil reads the FIRST's flux through shared iron — the turns ratio is the only new lever.
