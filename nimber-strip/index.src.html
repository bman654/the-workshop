The Nimber Strip

A strip of lit tiles. On your turn take 1, 2, or 3 stones off the live end; take the last stone to win. It looks like a fresh little game — but a hidden number rides every tile, and those numbers cycle 0, 1, 2, 3 all the way down the strip, a four-step staircase nobody put there. Each is a nimber, a Grundy value, found by a pure rule called mex — never by writing n mod 4. Pull the split lever and the strip cleaves into heaps, and the whole of Nim wakes up: you are LOST exactly when the heaps' nimbers XOR to zero, and the perfect move is the one that zeroes them. The flint opponent reads it all from the same rule the green chip proves.

The famous answer is g(n) = n mod 4 — but this bench never writes that. It runs the Sprague–Grundy rule grundy(k) = mex{grundy(k−1), grundy(k−2), grundy(k−3)} and lets the staircase fall out; the green chip only ever compares the live mex against n mod 4, so a broken rule breaks the beads loudly. Pull the lever and the disjunctive sum lights up: you are lost exactly when the place-lamps all go dark — the nim-sum is zero.
