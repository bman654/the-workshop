Why a switchyard. Netwalk is the estate's first rotate verb — you never add or remove a thing, only turn what is already there until the current flows. It cannot be lost: an un-powered tile is just half-lit in slate, waiting. The instant the source reaches every tile the whole lattice settles into gold. Each board is grown as a spanning tree from the source, scrambled, and kept only if it has a single solved orientation a no-guess solver can reach — and if every arm proves load-bearing.
