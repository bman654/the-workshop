✚ The Cross-Sums

Kakuro — a crossword in arithmetic. Each black clue-cell labels a run of white cells with a target sum; fill the digits 1–9 so every run hits its clue with no digit repeated within a run. Tap a white cell, then a digit (or use your keyboard). Never a guess: every board has a single solution reachable by pure combinatorial logic — which run-sums force which digit-sets.

Why arithmetic, not a chart. A Kakuro board is the estate's most combinatorial deduction puzzle: the proof lives in a table you can recite — a sum of k distinct digits 1–9 has a known set of possibilities (6-in-3 is only {1,2,3}; 17-in-2 is only {8,9}), and intersecting a cell's across- and down-runs pins it. You fill, you watch each run flush green as it tallies, you win when every run sums true.
