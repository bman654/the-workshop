Colophon · the strata self-test

This cut is not drawn — it is read. A build-time script walks the estate's full git log --reverse (every commit to the pinned asOf) and buckets each one, by committer date, between seven horizon commits — the days the way of working changed — into eight strata. The result is frozen as strata/strata.json, inlined into this page, and every figure you see is re-derived from it. The self-test battery below is single-sourced to strata/core.mjs with a Node twin strata/core.test.mjs (green, exit 0) — this pill computes the identical battery from the same bytes.
