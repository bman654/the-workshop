The Galton Board · the inverse
There, balls poured from a fixed law fall into a fixed bell — sampling forward. Here, the evidence updates which law you believe — inference backward. Two faces of one coin: a model that generates data, and data that updates a model.
Belief is a conserved liquid: a posterior is a probability, so the three vial levels always sum to Σ = 1 — mass is only poured sideways, never created or destroyed. Each bead shifts the pairwise log-odds by a fixed step — ln(Lic/Ljc) — so the slides simply add, and the order of the evidence is irrelevant: any shuffle of the same beads lands on the bit-identical posterior (we derive it from the per-colour tally, a sufficient statistic, never from order-dependent float products). A colour every urn is equally likely to emit — the Gray bead — carries a zero log-odds step, so it is a no-op. Throw a knife-switch and the law breaks honestly: skip the renormalizer and Σ drifts off 1 (belief is no longer a probability); count correlated evidence as independent and the bead runs off the rail, the log-odds overshooting past its true bound.  ·  Back to the Numbers Room
