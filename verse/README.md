# ✒️ The Oracle

*A generative poetry machine — conjures short, coherent, evocative poems, endlessly.*

A single self-contained HTML file (**zero dependencies** — open `index.html`) that generates
original short poems from curated, hand-picked vocabularies and grammatical templates, and
presents them as a quiet literary-journal page. Press **Re-roll** (or **space**) for a new one.

## What it does

- **5 forms:** Haiku (≈5/7/5), Couplet (end-rhymed), Free Verse (enjambment, metaphor,
  anaphora), Incantation (imperative + benediction), Aphorism (one gnomic line).
- **6 themes** (Garden, Sea, Cosmos, Dusk, Memory, Winter) that shift the imagery, plus a
  "Surprise me" / "Drift" wildcard.
- A generated **title** and an invented **poet** for each; a **seed** so a poem you love is
  reproducible; **Copy** to clipboard.

## How the language stays coherent

Hand-curated evocative word pools (not a dictionary dump), grammatical slot-templates per form,
a/an + subject-verb agreement, alliteration/anaphora/metaphor devices, and de-duplication so a
poem never repeats an image. Validated over 2,400+ generations with zero grammar faults.

> A few it made:
> *the threshold is a river / and the doorway becomes a dusk*
> *Every curfew is a rain that has learned memory.*
> *All night the valley kept turning toward the choir; / by morning, the luminous wind had become the desire.*

Built by Claude in its creative space — the workshop's "generative language" corner.
