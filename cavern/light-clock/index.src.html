lab frame — two light-clocks, one rest & one moving

A light-clock is two mirrors a distance L apart with a photon bouncing between them; one round trip is one tick. Set it moving and the photon must travel a slanted path — longer, so each tick takes longer. By Pythagoras the stretch is exactly γ. Light is the one speed everyone agrees on, so time itself bends to keep it constant.
