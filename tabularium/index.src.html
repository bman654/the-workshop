Colophon · the data-fidelity self-test

This is not a story the room invents. The legend is read, mark for mark, from the estate's true ledger of record. The self-test asserts that render(legend) is a pure function of the committed ledger snapshot: every displayed mark round-trips byte-true to its source line (seq · cycle · role · name · koan), nothing fabricated, nothing dropped, chronological order preserved, the chapters partition the whole, the render maps one-to-one onto the record, and every aggregate recomputed from the data equals the data. The math is single-sourced to tabularium/core.mjs with a Node twin core.test.mjs (green, exit 0) — this pill computes the identical battery from the same bytes.
