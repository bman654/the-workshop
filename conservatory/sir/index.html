A closed population of one unit flows S→I→R: susceptibles catch it, infecteds recover, recovereds never relapse. One number — the reproduction number R₀=βS₀/γ — gates everything: below 1 the outbreak dies; above 1 it sweeps to a peak exactly at S=γ/β.

S′=−βSI   I′=βSI−γI   R′=γI  ·  Φ=S+I−(γ/β)ln S = const

Trace it with the truthful integrator (RK4) and S+I+R holds at 1 to machine precision while Φ stays dead-flat; flip to a careless coarse step and the sum still holds — but the infected band is driven provably below zero, an impossible population. The break is positivity, not the sum.
