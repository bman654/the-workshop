Why is one crank enough? Because random mating sends any starting mix to p² : 2pq : q² in a single step, and that mix is a true fixed point — mate it again and nothing changes (p′ = AA + ½Aa = p, exactly). The pool is memoryless: it carries no record of how it got here, only the allele fraction p. Drain the heterozygotes with the knife-switch and the counts move, but only p survives — the one thing the jar will not forget.
