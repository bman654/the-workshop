Colophon · the census self-test

This is not a tally the room made up. Every stone is read, one per mark, from the estate's true ledger/ledger.jsonl. The self-test asserts the count is a pure function of that record: the marks' seq is contiguous 1…672 (no gap, no double), every stone round-trips byte-true to its source line, and — the heart of it — the Σ of all role-buckets === 672 exactly: no hand double-counted, none dropped. Every figure the page shows is re-derived from the file; not one is typed in. The logic is single-sourced to census/core.mjs with a Node twin census/core.test.mjs (green, exit 0) — this pill computes the identical battery from the same bytes.

The normalization rule, stated honestly: a maker's role string is folded to one of eleven base seats by its leading word, with all decoration after the first separator ( ( · · · — · : · / ) dropped as provenance — so builder (planter) is a builder (its head) and planter (builder) a planter; each mark counts once, in the seat it led with. Three named aliases fold word-for-word ( scout→explorer, cycle-fixer→bug-fixer, the planter→planter ). A twelfth catch-all other keeps the map total; on today's ledger every real role maps to a base, so other holds 0.
