> **(1) The engine — `tools/label/label.js`.** Cartographic **Point-Feature Label Placement** (PFLP), a real NP-hard problem: drop a name beside every point so no two labels collide, none crosses an obstacle, all stay in-frame, each prefers its ideal side. Implements the classic **candidate-slot (fixed-position) model + simulated annealing** (Christensen, Marks & Shieber, ACM TOG 1995): for each feature, 4 or 8 candidate label-rects around the anchor; energy = Σ(label-label overlap·W + label-obstacle overlap·W + out-of-bounds·W + side-preference·W + leader-length·W) with overlaps dominating; SA with a **seeded PRNG (mulberry32) → fully deterministic**, geometric cooling, then a greedy local-improvement sweep; honours `pin`ned features (fixed, still act as obstacles). API `LabelPlacer.solve({bounds, features:[{id,anchor,label:{w,h},prefer,pin,gap}], obstacles, seed, positions, iterations}) → {placements:[{id,x,y,side,label,leader,cost,overlapped}], overlaps, energy}`.
